For shops

See what our emails send you

Cigar Locker's emails link to shops near our members. Add one line to your site and we both see how many visitors from each email put something in the cart and how many buy.

How it works

Every link in our emails carries cl_ref, a random code that says nothing about the person. Our snippet keeps it on your site for 30 days. When a visitor who came from our email adds to the cart or places an order, it tells us the code, the order's total and number, and your site's name. Nothing about the visitor, their basket or their payment is sent, and visitors who did not come from our emails are never reported.

Our links also carry utm_source=cigarlocker, utm_medium=email and utm_campaign, so your own statistics show the visits too.

Any website

Put this on every page, before </body>:

<script src="https://cigarlocker.app/partner.js" async></script>

Then, where your site adds an item to the cart:

window.cigarLocker && cigarLocker.cart();

And on the order confirmation page, with the order's total and number:

window.cigarLocker && cigarLocker.purchase({ value: 86.40, order: 'A1234' });

Shopify

In Shopify admin, Settings > Customer events > Add custom pixel, name it "Cigar Locker", paste this, then Save and Connect:

const API = 'https://nypahhdmoxrfvwnfufdf.supabase.co/functions/v1/email/convert';
const ok = (r) => /^[0-9a-f]{16}$/.test(r || '');
async function ref() {
  const r = await browser.localStorage.getItem('cl_ref');
  return ok(r) ? r : null;
}
function send(event, extra) {
  ref().then((r) => {
    if (!r) return;
    const q = new URLSearchParams({ ref: r, event, site: init.context.document.location.hostname, ...extra });
    fetch(API + '?' + q, { method: 'POST', keepalive: true });
  });
}
analytics.subscribe('page_viewed', (event) => {
  const r = new URLSearchParams(event.context.document.location.search).get('cl_ref');
  if (ok(r)) browser.localStorage.setItem('cl_ref', r);
});
analytics.subscribe('product_added_to_cart', () => send('cart', {}));
analytics.subscribe('checkout_completed', (event) => {
  const c = event.data.checkout;
  send('purchase', { value: String(c.totalPrice.amount), order: String(c.order ? c.order.id : c.token) });
});

Affiliate programs

If your shop pays us through CJ, Awin, Impact, ShareASale or Rakuten, nothing needs adding: our links fill in the program's sub-ID (sid, clickref, subId1, afftrack or u1) with the same code, and your program's reports show it.
